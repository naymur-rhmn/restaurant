# 🍽️ Izakaya Restaurant

A modern and visually appealing restaurant website built with **React**, **Vite**, and **Tailwind CSS**. This project focuses on delivering an engaging user experience through attractive UI, smooth navigation, and responsive design. It is a frontend-only application created to showcase a premium restaurant website.

## ✨ Features

- 🎨 Modern and eye-catching UI
- 📱 Fully responsive design
- 🍔 Beautiful food and restaurant sections
- 🖼️ Interactive image carousel
- 🔥 Smooth user experience
- ⚡ Fast performance with Vite
- 🔗 Client-side routing with React Router
- 📢 Toast notifications
- 🔐 Firebase integration (Authentication ready)

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/your-username/restaurant.git
```

### Navigate into the project

```bash
cd restaurant
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

The application will be available at:

```
[http://localhost:5173](https://restaurant-38c89.web.app/)
```


## 📜 Available Scripts

## 🎯 Project Goal

The primary objective of this project is to create a **visually stunning restaurant website** that emphasizes modern UI/UX principles. Rather than focusing on complex business logic, the application showcases responsive layouts, attractive components, and an engaging browsing experience suitable for restaurants, cafés, or food businesses.
